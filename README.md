# 易行徒步规划制作器

**EasyHiking** 是面向中文用户的 Windows 徒步路线规划与攻略制作软件，把轨迹整理、离线路由规划、地图查看、高程分析、攻略节点、多日行程和 Excel 攻略导出放在同一个工作区中。

适合需要整理 GPX / KML / KMZ、规划多日徒步行程、管理图片标注，并制作可打印或分享的徒步攻略的用户。

[下载安装包](https://github.com/gyleslee/EasyHiking/releases) · [操作说明](docs/易行徒步规划制作器-操作说明.md) · [反馈问题](https://github.com/gyleslee/EasyHiking/issues) · [源码编译](BUILDING.md)

## 主要作用

将“导入或规划路线 → 整理轨迹与节点 → 分析距离和高程 → 填写攻略 → 安排每日行程 → 导出攻略”串联起来，减少多个工具之间反复转换文件和手工整理表格的工作。

软件以数据正确性和项目可靠性为优先：原始计算轨迹与地图显示副本分离，轨迹编辑不自动覆盖原始 GPX/KML，重新分析保留人工填写的攻略内容。

## 主要功能

| 模块 | 功能 |
|---|---|
| 多项目工作区 | 同时打开多个项目；一个项目可容纳多条轨迹；区分当前工作轨迹和唯一主攻略轨迹；保存、自动保存与异常恢复。 |
| 轨迹与标注导入 | 支持 GPX、KML、KMZ；统一导入轨迹、普通标注、攻略节点及图片引用；预览后选择导入内容。 |
| 轨迹编辑 | 地图 Ctrl 多选，拆分、裁剪、反转、合并和连接；连接顺序手动指定；支持删除来源时转移关联标注及撤销重做。 |
| 路线规划 | BRouter 本地徒步路由、手绘规划与混合规划；路由数据下载、导入及管理；规划结果生成整条轨迹。 |
| 地图与图层 | 自定义 XYZ 底图及两个在线叠加层；坐标系选择与纠偏；图源缓存、透明度和缓存清理。 |
| 离线地图 | 多边形选区、层级选择、大小预估、下载进度及续传；生成 PMTiles，优先读取已下载区域；超出包内层级时继续在线加载。 |
| 2D / 3D 地形 | 使用本地 DEM 生成 3D 地形；调整地形夸张、旋转、倾斜和一键向北。 |
| DEM 等高线与阴影 | 按视野后台生成并缓存；主等高线加粗；调整颜色、透明度及阴影强度；与在线图层独立控制。 |
| OSM 离线路网 | 读取 BRouter rd5 数据中的道路并独立叠加；道路类型单行设置，提供样式示例，可调整最小与最大显示层级。 |
| 高程与里程分析 | 挂载多套 GeoTIFF/HGT DEM；GPS 与 DEM 高程查看和对比；交互式海拔剖面、攻略节点黄点及点击定位地图。 |
| 攻略节点与图片 | 普通标注和攻略节点互转、批量编辑、轨迹吸附及重合路段候选选择；KMZ 图片与网络图片按需下载。 |
| 全局收藏点 | 收藏夹、搜索、图片、地图悬停信息、拖动编辑及 KMZ 导出；跨项目使用。 |
| 攻略与多日行程 | 分段攻略、路况及地点情况；多套行进方案、每日起终点、出发时间、计划抵达时间和备注。 |
| 文件导出 | 导出 GPX、KML、含图片的 KMZ，以及基于既定模板的 Excel 最终攻略。 |
| 界面设置 | 简体中文界面；面板显隐、拖动比例及表格列宽保存；设置跨项目复用。 |

### 轨迹编辑与数据保护

- 主攻略轨迹及其拆分分段受保护，不能直接参与合并、连接或拆分。需要编辑时，先转为普通轨迹；所属攻略节点同步转为普通标注。编辑后可重新设为主攻略轨迹。
- 拆分分段使用“原轨迹名称（序号）”命名；删除分段不回收序号，保存重开后继续递增。
- 合并与连接可同时处理整条轨迹和拆分分段；只删除选中的分段时，其余分段保留。
- 项目文件保存人工攻略内容、图片和关联信息。请保留原始轨迹及独立备份。

### 高程与统计说明

最终攻略统计以既定的 **FathomDEM** 高程来源为基准；GPX/KML 海拔及 BRouter 高程不自动替代该基准。GPS 和其他 DEM 可用于查看与对比。

当前里程分类采用已确认的方案 A：每 5 米采样、20 米平滑、10 米坡度窗口；坡度绝对值不超过 2.1% 为平路，超过 2.1% 为上升或下降路段；上升坡度大于 2.1% 且小于 35% 为缓坡，大于或等于 35% 为陡坡。算法参数可调整，不能据此宣称已完整复现 Locus 的所有内部统计算法。

## 下载与首次使用

从 [Releases](https://github.com/gyleslee/EasyHiking/releases) 选择对应系统的安装包：

- Windows 10 / 11 64 位：`EasyHiking-{版本号}-Windows10-11-x64-Setup.exe`
- Windows 7 SP1 64 位：`EasyHiking-{版本号}-Windows7-x64-Setup.exe`

安装后依照首次设置向导挂载 DEM、导入或下载 BRouter 路由数据。安装包不包含 DEM、已下载路由、个人项目、收藏及离线地图。

程序默认安装到 `C:\Program Files\EasyHiking`，可自行修改。个人数据保留 Windows 用户 LocalAppData 路径层级，盘符随程序安装盘改变；卸载默认保留个人数据，并提供明确的删除选项。

源码只保留内置公开 OSM 示例，不包含开发者个人图源配置、请求头或密钥。现成安装包的默认图源与源码示例可能不同。地图、DEM、路由数据与服务访问条件由各自提供方规定；图源存在于列表中不表示获得离线下载或再分发许可。

## 技术与开发

主分支使用 C#、.NET 10、WPF、WebView2 和 MapLibre；Windows 7 兼容源码位于 `compat/windows7`，使用 .NET 6 与相应兼容组件。核心计算与 GUI 分离，提供 xUnit 及 Web 地图自动测试。
